Task Management Components Test

1. Task Table Component

Test Checklist:

  • Empty state displays correctly
  • Loading state displays correctly
  • Task rows render with correct data
  • Status badges have correct colors
  • Proxy info formats correctly (IP:Port, Bekliyor, Proxy Silinmiş)
  • Log buttons are clickable
  • Responsive design (resize window to test mobile view)

2. Task Creation Modal

Test Checklist:

  • Modal opens and closes correctly
  • Accounts load from API
  • Account selection works
  • Create button is disabled when no account selected
  • Create button is enabled when account selected
  • Task creation API call works
  • Success notification displays
  • Error handling works

3. Log Viewer Modal

Test Checklist:

  • Modal opens with task ID
  • Logs load from API
  • Logs display in chronological order
  • Log levels have correct colors (info: blue, warning: yellow, error: red)
  • Timestamps format correctly
  • Empty state displays when no logs
  • Modal closes correctly

4. Responsive Design Test

Test Instructions:

  • Resize browser window to < 768px width
  • Task table should switch to card layout
  • Modals should remain centered and scrollable
  • Buttons should be touch-friendly (minimum 44x44px)
